# 2026_登山活動

2026 鐵砧山登山活動報名網站。活動日期：2026/11/20；集合地點：鐵砧山登山口。

## 網站

GitHub Pages 網址：部署後補上。

## 建立報名試算表與 Apps Script

1. 在 Google 試算表建立空白試算表，並從該試算表選擇「擴充功能 → Apps Script」。
2. 將本專案的 `Code.gs` 貼入 Apps Script 編輯器並儲存。
3. 在編輯器選取並執行 `setupSheet`，完成 Google 授權。試算表會命名為 `2026_登山活動`，並建立標題列；「電話」欄會設為純文字。
4. 選擇「部署 → 新增部署作業 → 網頁應用程式」，設定「執行身分」為自己，存取權設為「任何人」，完成授權並部署。
5. 複製網頁應用程式網址，填入 `index.html` 的 `APPS_SCRIPT_URL` 常數，然後重新發布網站。

`doPost` 會將每筆報名資料寫入「報名資料」工作表。請勿在網站原始碼中放入任何 Google 帳號憑證或試算表私密資料。

## 本機預覽

直接以瀏覽器開啟 `index.html`。Apps Script 網址尚未設定前，表單會提示報名系統尚未完成設定。
